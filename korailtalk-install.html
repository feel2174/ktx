코레일톡(코레일+) 앱 설치 방법 — 안드로이드·아이폰

3줄 요약 코레일톡은 업데이트되면서 이름이 코레일+(코레일플러스)로 바뀌었습니다. 안드로이드는 Play 스토어, 아이폰은 App Store에서 '코레일톡' 또는 '코레일플러스'를 검색해 설치하면 됩니다. 설치가 안 되면 OS 버전(안드로이드 12.0 이상·iOS 16.0 이상)과 저장공간을 확인하고, APK 같은 비공식 파일은 절대 내려받지 마세요.

코레일톡? 코레일+? 코레일플러스? 이름부터 정리

코레일톡 설치(코레일플러스 설치)를 검색하면 나오는 셋은 같은 계열의 앱입니다. 기존 코레일톡을 최신 버전으로 업데이트하면 코레일+(코레일플러스)로 바뀝니다. 이름이 아직 코레일톡이라고 해서 다른 앱을 찾을 필요는 없습니다. 개발사는 한국철도공사이며, 이 이름·개발사가 맞는지 확인하면 사칭 앱을 피할 수 있습니다.

지금 바로 코레일톡(코레일+)을 스토어에서 설치해 두세요.

📱 App Store에서 설치 🤖 Google Play에서 설치

안드로이드(삼성·LG 등)에서 설치하기

  1. 홈 화면에서 Play 스토어를 엽니다.
  2. 검색창에 코레일톡 또는 코레일플러스를 입력해 검색합니다.
  3. 개발사가 한국철도공사(코레일)인지 확인하고 설치를 누릅니다.
  4. 설치 중 권한 동의 안내가 나오면 확인하고 진행합니다.

아이폰(iPhone)에서 설치하기

  1. 홈 화면에서 App Store를 엽니다.
  2. 검색 탭에서 코레일톡 또는 코레일플러스를 검색합니다.
  3. 개발사가 한국철도공사인지 확인하고 받기를 눌러 설치합니다.
  4. 필요 시 Face ID·암호로 다운로드를 승인합니다.

설치 후 해야 할 일

  1. 통합회원 로그인 또는 회원가입 : 코레일·SR 통합회원으로 로그인합니다. 계정이 없다면 회원가입을 먼저 하고, SR(SRT) 단독회원은 통합회원 전환을 마쳐야 로그인이 됩니다. (통합회원 전환 안내)
  2. 본인인증·간편비밀번호 등록 : 최초 로그인 시 본인인증과 간편 비밀번호를 설정합니다.
  3. 결제수단 미리 등록 : 카드·간편결제를 등록해두면 예매 때 좌석 선점 후 빠르게 결제할 수 있습니다.

설치·업데이트가 안 될 때

  • OS 버전 확인 : 코레일 안내 기준 안드로이드 12.0 이상, iOS 16.0 이상을 권장합니다. 하위 버전 기기에서는 설치나 실행이 막힐 수 있습니다.
  • 저장공간 확보 : 저장공간이 부족하면 설치가 중단됩니다. 불필요한 파일을 지우고 다시 시도하세요.
  • 스토어에서 업데이트 : 이미 코레일톡이 있다면 Play 스토어·App Store에서 최신 버전으로 업데이트합니다.
  • 네트워크 전환 : Wi-Fi에서 다운로드가 멈추면 모바일 데이터(LTE·5G)로 바꿔 시도하세요.
  • APK·비공식 설치 금지 : 설치가 안 된다고 외부에서 APK나 비공식 설치 파일을 내려받지 마세요. 공식 스토어가 아닌 앱은 악성코드·결제정보 탈취 위험이 있어 위험합니다.
광고

코레일 공식 권장 이용환경

코레일 이용환경 안내에 따르면 권장 브라우저는 크롬·삼성인터넷·사파리, 권장 네트워크는 유선인터넷 또는 LTE·5G입니다(이동 중 Wi-Fi는 끊길 수 있음). 앱이 잘 열리지 않으면 SNS·포털 인앱 브라우저로 접속하는 것을 피하고, 회사 네트워크·보안 정책을 확인한 뒤 모바일 데이터로 접속해 보세요.

예매 오픈 전에 앱 설치·업데이트·로그인까지 미리 끝내두는 것이 가장 중요합니다.

자주 묻는 질문

코레일톡과 코레일+는 다른 앱인가요?
같은 앱입니다. 코레일톡을 최신 버전으로 업데이트하면 코레일+(코레일플러스)로 이름이 바뀝니다. 새로 설치할 필요는 없습니다.
앱 설치가 자꾸 실패해요.
기기의 OS 버전(안드로이드 12.0 이상·iOS 16.0 이상)과 저장공간을 확인하고, Wi-Fi 대신 모바일 데이터로 시도해 보세요. APK 등 비공식 파일은 내려받지 마세요.
설치했는데 로그인이 안 됩니다.
코레일·SR 통합회원으로 로그인해야 합니다. SR 단독회원이라면 통합회원 전환을 먼저 마쳐야 로그인할 수 있습니다.
앱 없이 예매할 수는 없나요?
코레일 홈페이지(PC·모바일 웹)나 철도고객센터(1544-8545) 전화로도 예매할 수 있습니다. 다만 명절에는 앱이 좌석 선택·결제가 가장 빠릅니다.
